# Societal Innovation Portal

SIH 2026 — a civic-issue reporting platform for Jharkhand: citizens report
problems, AI triages them, admins assign them to universities, universities
propose solutions, and industries fund them.

- New here? Start with [AGENTS.md](./AGENTS.md) and [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md).
- API contract: [docs/API_CONTRACT.md](./docs/API_CONTRACT.md).
- Open tickets: [docs/TASK_BREAKDOWN.md](./docs/TASK_BREAKDOWN.md).
- Contributing: [CONTRIBUTING.md](./CONTRIBUTING.md).
